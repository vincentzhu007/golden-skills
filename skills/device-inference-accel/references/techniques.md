# 技术卡：按瓶颈取

每张卡给出前提、预期收益、精度风险、验证方式。预期收益是方向，不是承诺，必须用基线实测。先读主技能的剖析步骤，确认瓶颈后再取卡。

## 量化（int8/int4，PTQ/QAT）

- **前提**：权重或激活可量化；目标后端有对应低比特内核；校准集覆盖真实分布。
- **预期收益**：权重访存下降，带宽受限的解码阶段通常最明显；算力受限且无低比特加速时收益有限。
- **精度风险**：离群激活、per-channel 与 per-tensor 差异、KV cache 量化更敏感。
- **验证**：同输入对比 cosine/KL/top-1/perplexity，写明容差；对任务指标抽查生成质量。

## 算子融合与图优化

- **前提**：融合不改变数值语义；后端支持融合算子。
- **预期收益**：减少 kernel 启动与中间张量访存，调度受限时收益高。
- **精度风险**：累加顺序、激活近似、布局转换。
- **验证**：逐 op 对比加端到端精度；记录 kernel 数与图变换次数。

## KV cache 与内存复用

- **前提**：能区分逻辑长度与物理容量；复用不跨请求泄漏。
- **预期收益**：降低峰值内存与分配次数，影响并发上限与最大序列。
- **精度风险**：复用未清零、跨请求状态污染、量化 KV。
- **验证**：长序列与并发下的正确性；峰值内存与 p99 延迟。

## NPU/GPU delegate 与后端适配

- **前提**：算子覆盖、布局与对齐、量化格式匹配。
- **预期收益**：卸载到专用单元，提升算力与能效。
- **精度风险**：回退边界、不同精度路径、算子近似。
- **验证**：覆盖表（哪些 op 走 delegate）、回退计数、端到端精度与延迟。

## 线程/并行/调度与端到端工程

- **前提**：线程数与大核绑定可配；无数据竞争。
- **预期收益**：减少排队与空转，改善 tail latency。
- **精度风险**：通常无；并发下的状态隔离要验证。
- **验证**：不同并发与线程数下的吞吐和 p99；CPU 与 NPU 协同。

## 性能建模：Roofline 与 Top-down

- **前提**：能估 FLOPs 与 bytes；有可达峰值算力与带宽。
- **预期收益**：判断算力或带宽受限，给理论下界与优化方向。
- **风险**：估算不是实测。
- **验证**：`scripts/roofline.py` 下界与 `scripts/bench.py` 实测对比，解释差距来源。

## Flash offloading（Dense/MoE）

- **前提**：权重可按层或按专家换入；带宽与存储足够。
- **预期收益**：突破内存上限，跑更大模型；MoE 只换活跃专家。
- **精度风险**：换入换出正确性、量化。
- **验证**：首 token 与稳态延迟；换入次数与带宽占用。

## 长序列 prefill 加速

- **前提**：注意力是瓶颈；可做分块、融合或稀疏。
- **预期收益**：降低 TTFT 与峰值内存。
- **精度风险**：注意力近似、掩码与位置编码。
- **验证**：不同序列长度下的 TTFT 与精度。

## 投机解码

- **前提**：有草稿模型或 n-gram 检索草稿；可批量验证。
- **预期收益**：解码阶段吞吐提升，收益由接受率决定。
- **精度风险**：验证策略必须保证输出分布一致（如拒绝采样）。
- **验证**：接受率、TPOT、输出与基线的一致性抽样。

## 通用验证规则

- 一次只改一个变量，退化即回退。
- 精度对齐写明指标、容差、参考实现与输入集。
- 性能报分布（p50/p90/p99），同基线同环境。
- 结论写明设备、模型、形状与版本；未测组合标为待验证。
