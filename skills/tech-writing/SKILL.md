# 技术文章写作

## 边界

- 输入是素材：笔记、diff、实验数据、论文、复现记录。缺证据时标注待补，不编造。
- 不写成产品营销稿；个人观点转成适用条件、取舍与验证方式。

## 工作流

1. **定主张与读者**：一句话写出这篇文章要让读者相信或学会什么，以及读者已有的背景。写不出主张就先不写。
2. **取材并分层**：区分事实（可复现或可引用）、计算估算（写明模型与假设）、个人判断（标注为观点）。数字必须有基线、单位和测量条件。
3. **选形态与结构**：按类型取[文章骨架](references/article-shapes.md)；同一信息只选一种主要表达（图、表、正文择一），不重复。
4. **写作**：一段一个主张；先具体后抽象；术语一次定义后统一；删 AI 味，包括空泛形容词、排比、口号和重复总结。
5. **校验**：引用可回溯，结论不超出证据，长度匹配受众，代码片段可运行或明确标为伪代码。

## 完成标准

- 主张清晰，证据分层且可追溯，结构匹配文章类型，未标注假设为零。
